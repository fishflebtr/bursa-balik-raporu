SAATLİK TAHMİN

Saat Aralığı Hava Sıcaklık Rüzgar Rüzgar Hızı Dalga Balık Aktivitesi

LRF ÖNERİLERİ

  • ✓ Gramaj: 0.5g - 5g jighead / 1-7g metal jig
  • ✓ Silikon: 2-5 cm (Ecogear, Keitech tarzı)
  • ✓ Renk: Beyaz, chartreuse, pembe, doğal kefal
  • ✓ Teknik: Yavaş sarsıntılı çekiş, dip-orta su
  • ✓ Hedef: İstavrit, mırmır, mezgit, küçük lüfer

SPİN ÖNERİLERİ

  • ✓ Gramaj: 7-21g (kıyı) / 14-28g (rüzgarlı)
  • ✓ Sahte: 7-12 cm minnow, twichbait, metal jig
  • ✓ Renk: Doğal sardalya-kefal, mavi-gümüş, pembe
  • ✓ Teknik: Orta-hızlı retrieve, stop&go, twich
  • ✓ Hedef: Lüfer, çinekop, levrek, palamut
